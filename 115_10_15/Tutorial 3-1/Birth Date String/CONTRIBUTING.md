# Contribution Guidelines

## Guidelines

本專案遵循以下 UI 與控制項顯示準則，所有貢獻者在修改 Windows Forms UI 時請遵守：

- 所有使用者介面（UI）元件的 `Text` 屬性必須以繁體中文（zh-TW）撰寫。
- 預設字型請使用 `Microsoft JhengHei`（微軟正黑體），字型大小為 `18pt`。
- 請放大所有元件大小（高度與寬度）以確保能顯示完整文字，並增加元件之間的間距以改善可讀性與操作性。
- 控制項之間應留有足夠距離，避免元件重疊或文字被切斷。
- 如果新增元件或改動版面，請在 Pull Request 描述中說明改動與原因，並附上畫面截圖。

## Standards

- Label、Button、TextBox 等常見控制項的最小字高應對應 18pt 字型，建議控制項高度不小於 40px（Windows Forms 單位）。
- 主要按鈕大小建議 140x50 或更大，並在按鈕間保留 16px 以上間距。
- 請保持表單整體視覺一致性。

## Review

PR 審查時將檢查 UI 文案是否為繁體中文、字型大小是否為 18pt，以及控制項大小與間距是否合適。
